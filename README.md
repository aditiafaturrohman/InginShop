# NusaShop — E-Commerce HTML/CSS/JavaScript

Website demo e-commerce front-end tanpa framework.

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka `index.html` menggunakan browser (Chrome/Edge/Firefox).
3. Tidak membutuhkan server untuk fitur demo.

## Fitur
- Responsive desktop/tablet/mobile
- Search produk
- Filter kategori
- Sorting harga/rating
- Keranjang belanja
- Tambah/kurang jumlah
- Hapus item/kosongkan keranjang
- Wishlist
- Dark mode
- localStorage
- Checkout demo
- Promo
- Mobile navigation

## Catatan
Ini adalah website front-end. Pembayaran, database, login, stok, dan pengiriman belum terhubung ke backend/API nyata.
